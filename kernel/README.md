# Cogzidel Kernel

The Kernel contains the foundational specifications of the Cogzidel Institution.

Everything else derives from these documents.

## Constitution.md

Defines who Cogzidel is and the laws that govern the institution.

## ThinkingOS.md

Defines how the institution thinks.

## AIDPL.md

Defines how the institution builds.

## LearningOS.md

Defines how the institution learns.

## Kernel Rules

1. Products shall never redefine the Kernel.
2. The Kernel grows through evidence, never through ideas alone.
3. The Kernel remains intentionally small.
4. Every product is a Kernel validation exercise.
5. Kernel changes require Founder authorization.

> Think Better. Build Better. Learn Forever.
