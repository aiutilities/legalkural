# Sprint Execution Contract v1.0

## Purpose

Define the minimum execution contract for every AIDPL sprint.

## Required Fields

- Project
- Sprint
- Owner
- Estimate
- Deadline
- Evidence
- Escalation

## Engineering Law

Every claim is evidence-derived.

## Evidence

- Source Code
- Tests
- Git Commit

## Escalation

30 min  -> PM

60 min  -> CTO

90 min  -> CEO

120 min -> MAYDAY
