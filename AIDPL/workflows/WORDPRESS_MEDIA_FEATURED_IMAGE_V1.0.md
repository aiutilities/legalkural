# WordPress Media + Featured Image v1.0

## Frozen Modes

1. No image
2. Manual image upload
3. AI-generated image

## AI Prompt Flow

- Recommend prompt from article title and excerpt
- Allow editor replacement
- Allow later AI polishing
- Generate image only after prompt selection
- Return to prompt when image is rejected

## Metadata

- Caption
- Alt text
- Description
- Media title (future upload integration)

## Important Rule

An empty AI prompt is valid at intake because the system
generates a recommended prompt before image generation.
Publishing without an image remains valid.
